## 快速开始

### 1. 登录系统

打开浏览器访问系统地址，使用账号密码登录。

```
首次登录请联系管理员获取账号
登录后请立即修改密码（右上角头像 → 设置）
```

### 2. 主界面介绍

登录后看到4个主要功能：

- **📊 仪表板** - 查看数据统计
- **🎯 工作台** - 日常工作的主要界面（看板）
- **📋 项目管理** - 管理软件项目
- **🗓️ 迭代管理** - 管理Sprint迭代

## 创建迭代

> 迭代(Sprint)是一周的工作周期，例如 2025-01 表示2025年第1周

### 步骤

1. 点击左侧菜单 **🗓️ 迭代管理**
2. 点击右上角 **+ 创建迭代** 按钮
3. 填写迭代信息：
   - **迭代编号**: 例如 `2025-01`（系统会自动建议）
   - **开始日期**: 选择周一
   - **结束日期**: 选择周日
4. 点击 **保存** 完成创建
5. 点击 **激活** 按钮，将新迭代设为当前工作迭代

```
💡 小贴士：一次只能有一个激活的迭代
```

## 管理项目

> 项目是你要开发的软件系统

### 创建项目

1. 点击左侧菜单 **📋 项目管理**
2. 点击 **+ 新建项目** 按钮
3. 填写项目信息：
   - **项目名称**: 例如 `PM5100标检上位机`
   - **项目类型**: 新研发 / 二次开发 / 运维
   - **需求来源**: 内部需求 / 外部需求
   - **部门**: 选择所属部门
   - **负责人**: 选择项目负责人
   - **项目组成员**: 选择团队成员
4. 点击 **保存**

### 将项目加入迭代

1. 在项目列表中，点击项目右侧的 **⋯** 菜单
2. 选择 **加入当前迭代**
3. 现在可以在工作台中看到这个项目了

## 添加需求和任务

> 需求(Story)是功能点，任务(Task)是具体要做的事

### 方式一：在工作台添加（推荐）

1. 点击左侧菜单 **🎯 工作台**
2. 选择当前迭代和项目
3. 点击项目卡片右上角的 **···** 菜单
4. 选择 **添加Story** 或 **添加Task**

**添加需求(Story):**
- **标题**: 例如 `完成用户登录功能`
- **描述**: 简单描述功能要求
- **状态**: 未开始 / 进行中 / 已完成
- **进度**: 0-100%
- **负责人**: 选择负责人
- **关键节点**: 例如 `需求评审-1/15, 开发完成-1/20`

**添加任务(Task):**
- **标题**: 例如 `编写登录API接口`
- **所属需求**: 选择关联的Story
- **状态**: 未开始 / 进行中 / 已完成
- **负责人**: 选择负责人

### 方式二：在列表视图批量添加

1. 在工作台点击右上角 **切换到列表视图**
2. 可以快速批量编辑和添加

```
💡 小贴士：
- Story 是大的功能模块
- Task 是实现这个功能需要做的具体事情
- 一个 Story 可以包含多个 Task
```

## 使用看板

> 看板是管理工作进度的可视化工具

### 看板布局

每个项目有3列：

- **未开始** - 计划要做的事
- **进行中** - 正在做的事
- **已完成** - 做完的事

### 拖拽更新状态

1. 用鼠标拖动任务卡片
2. 拖到对应的列（未开始/进行中/已完成）
3. 系统自动保存状态

### 编辑任务

1. 点击任务卡片
2. 在弹出窗口中编辑信息：
   - 修改标题、描述
   - 更新进度（0-100%）
   - 填写风险和应对措施
3. 点击 **保存**

### 快速操作

- **删除**: 点击卡片右上角 **×** 按钮
- **查看详情**: 点击卡片查看完整信息

```
💡 小贴士：
- 拖拽比手动修改状态更快
- 及时更新进度，让团队了解你的工作情况
```

## 导出周报

> 系统自动汇总生成Excel周报

### 导出团队周报（管理员）

1. 点击左侧菜单 **🗓️ 迭代管理**
2. 找到要导出的迭代
3. 点击右侧 **导出周报** 按钮
4. 系统自动下载Excel文件

**周报包含:**
- 所有项目的进展情况
- 本周完成的Story和Task
- 下周计划
- 风险和应对措施
- 完成率统计

### 导出个人周报

1. 点击左侧菜单 **🗓️ 迭代管理**
2. 找到要导出的迭代
3. 点击右侧 **导出个人周报** 按钮
4. 系统自动下载你负责的工作内容

```
💡 小贴士：
- 每周五导出周报，周一复盘
- 个人周报只包含你负责的工作
```

## 常见问题

### Q: 如何修改密码？
A: 右上角头像 → 设置 → 修改密码

### Q: 任务拖错了怎么办？
A: 再拖回去就行了，或者点击卡片手动修改状态

### Q: 如何删除迭代或项目？
A: 联系系统管理员，普通用户无删除权限（防止误删）

### Q: 看不到某个项目？
A: 确认项目已加入当前迭代（项目管理 → 加入当前迭代）

### Q: 周报导出失败？
A: 检查网络连接，或稍后重试。如持续失败联系管理员

### Q: 如何查看历史迭代？
A: 工作台 → 迭代选择器 → 选择历史迭代查看

## 使用流程图

```
每周工作流程：

周一
├─ 激活新迭代（2025-XX）
├─ 将项目加入当前迭代
└─ 添加本周的Story和Task

周二-周四
├─ 在工作台拖拽任务（未开始 → 进行中 → 已完成）
├─ 更新进度（0% → 50% → 100%）
└─ 填写风险和应对措施

周五
├─ 确认所有任务状态
├─ 导出周报
└─ 发送给部门经理

周六-周日
└─ 休息 😊
```
