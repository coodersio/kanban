交互说明

这版把你的意思落成两层能力：新建页里支持“单选直接引入”，引入页里保留“多选批量引入”。

1
新建项目页
用户先输入项目名称。下面出现已有项目建议，但这时仍停留在“新建项目”Tab 内。
2
点选建议项
一旦点击某个已有项目，下面的新建表单直接隐藏，改成“单选直接引入”状态，不再要求填写描述、部门等字段。
3
如果用户不点建议
那就继续展示完整新建表单。也就是说，同一个 Tab 内自然分出“单选直接引入”和“继续新建”两条路径。
4
引入旧项目页
这个 Tab 仍然存在，因为它解决的是“搜索、滚动、批量多选”场景，和新建页里的单选快捷复用不是一回事。
当前状态：查看“新建项目”页。你可以试试输入“壁挂炉”、“MES”或“自动标检”，再点某个建议项，观察表单是否隐藏。
