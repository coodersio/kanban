# KanBan 快速参考卡

> 常用操作一页搞定

---

## 🚀 每周工作流程

| 时间 | 操作 | 位置 |
|------|------|------|
| **周一** | 1. 创建新迭代<br>2. 激活迭代<br>3. 添加项目到迭代 | 迭代管理 |
| **周二-周四** | 1. 拖拽任务更新状态<br>2. 更新进度<br>3. 记录风险 | 工作台 |
| **周五** | 导出周报 | 迭代管理 |

---

## 📌 核心操作

### 创建迭代
```
迭代管理 → 创建迭代 → 填写信息 → 保存 → 激活
```

### 添加项目
```
项目管理 → 新建项目 → 填写信息 → 保存 → 加入当前迭代
```

### 添加需求/任务
```
工作台 → 选择项目 → ··· 菜单 → 添加Story/Task
```

### 更新状态（拖拽）
```
工作台 → 拖动任务卡片 → 放到目标列
```

### 导出周报
```
迭代管理 → 找到迭代 → 导出周报/导出个人周报
```

---

## 🎯 任务状态

| 状态 | 说明 | 操作 |
|------|------|------|
| **未开始** | 计划要做的 | 拖到"进行中"开始工作 |
| **进行中** | 正在做的 | 更新进度，完成后拖到"已完成" |
| **已完成** | 做完的 | 确认进度100%，记录到周报 |

---

## 💡 小技巧

1. **快速更新**: 直接拖拽比点击编辑更快
2. **批量操作**: 切换到列表视图可以批量编辑
3. **及时记录**: 随时更新进度和风险，不要等到周五
4. **查看历史**: 工作台可以查看任何历史迭代
5. **个人周报**: 只包含你负责的工作，汇报更方便

## 🔑 权限说明

| 角色 | 权限 |
|------|------|
| **管理员** | 所有操作 + 用户管理 |
| **开发者** | 创建项目、管理自己的任务、导出个人周报 |
| **外部人员** | 仅查看权限 |

---

## ⚠️ 注意事项

- ❌ 不要删除别人的任务
- ❌ 不要随意修改别人负责的项目
- ✅ 及时更新进度
- ✅ 如实填写风险和应对
- ✅ 周五前完成周报导出

## 📞 快速求助

| 问题 | 解决方案 |
|------|----------|
